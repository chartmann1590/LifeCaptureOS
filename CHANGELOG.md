# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-01-12

### Added
- Initial MVP release of LifeCaptureOS.
- **Firmware**: ESP32-CAM support, SD card storage, BLE control, and Wi-Fi resumable uploads.
- **Android App**: Kotlin/Compose UI, BLE provisioning, thumbnail gallery, and device control.
- **Backend**: FastAPI server, resumable upload API, Ollama (moondream) AI integration for memories.
- **AI Features**: Semantic search, automated daily recap videos, and AI-powered memory summaries.
- **Documentation**: Comprehensive guides for setup, flashing, and protocols.

### Changed
- Refined Android UI with Cyber/Modern theme.
- Improved upload reliability on ESP32-CAM.

### Fixed
- Various BLE connectivity and video playback issues in the Android app.
